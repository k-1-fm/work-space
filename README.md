## 開発ルール

- 変更は Pull Request で取り込む
- コミットメッセージはプレフィックスをつける

### コミットメッセージのプレフィックス

| プレフィックス | 用途 |
| --- | --- |
| `Add` | 新規ファイル・機能の追加 |
| `Update` | 既存機能の修正（バグではない） |
| `Fix` | バグ修正 |
| `Remove` | ファイル・機能の削除 |
